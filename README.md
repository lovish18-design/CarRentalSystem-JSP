# 🚗 Car Rental System (Java Servlets)

A **Car Rental System** built using **Java Servlets**, **JSP**, and **MySQL** that allows customers to browse, book, and manage car rentals online.  
This system also includes an admin panel for managing cars, users, and rental records.

## 🧩 Overview

This project is a **web-based car rental management application** that simplifies the process of renting cars for customers and managing rental operations for administrators.

### Key Objectives:
- Allow users to view available cars and make reservations online.
- Provide an admin dashboard to manage cars, bookings, and users.
- Handle authentication and authorization securely.
- Demonstrate the use of Java EE technologies (Servlets & JSP) with MVC architecture.

---

## ✨ Features

### 👤 User Features
- User registration and login  
- Search available cars by type, model, or price  
- Book and cancel car rentals  
- View booking history  

### 🔧 Admin Features
- Admin login  
- Add, update, and remove cars  
- Manage users and bookings  
- View system reports  

### 🧱 General
- Session management  
- Input validation  
- Responsive UI using Bootstrap

## 🧮 System Architecture

The system follows the **MVC (Model–View–Controller)** architecture:

- **Model**: Represents business logic and database entities (Car, User, Booking)
- **View**: JSP pages for displaying data to the user
- **Controller**: Java Servlets handling requests and responses
